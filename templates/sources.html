Modello

Perché i named graph

La reificazione standard richiederebbe quattro triple per ogni asserzione e renderebbe le query molto più verbose. Con i named graph la provenienza resta implicita nel contesto della quadrupla: 

GRAPH :TMDB {
  :TMDB27205 :hasTrope :dreams .
}

SELECT ?source WHERE {
  GRAPH ?source {
    :TMDB27205 :hasTrope :dreams
  }
}

Separazione dei livelli

  • Ontologia:Ontology
  • Dati di fonteWikidata, DBpedia, TMDB
  • Dati derivati:Derived
  • Inferenze:Inferred

Le triple inferite non sovrascrivono i dati espliciti: vengono isolate, così la demo può mostrare che cosa ha prodotto il reasoner.
